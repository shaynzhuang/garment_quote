# 手机报价小工具 · 设计文档

日期：2026-07-05

## 背景

用户在毛衣/针织工厂做紧急报价，目前流程是在手机备忘录里复制粘贴一段计算公式，手动填数字。希望做一个单文件 HTML 小工具，替代这个流程：拍样衣照片、填成本项、自动算出总价，并能定期把历史报价导出成 Excel。

与已有的"样衣管家"(sample_tracker) ERP 项目无关，是完全独立、免安装、可离线使用的单页工具。

## 页面结构

顶部两个标签，JS 切换显示，不跳转页面：

- **报价**：录入与计算
- **历史**：已保存的报价记录列表 + 导出

## 报价页字段与开关

每个成本项右侧都有一个开关（默认开）。关闭时该项**不参与计算**（贡献视为 0），但输入框内容保留、变灰，方便下次重新打开复用数值——不是清空。

| 分组 | 字段 | 说明 | 开关 |
|---|---|---|---|
| 基本信息 | 样衣图片 | `<input type=file accept=image/*>`（不加 capture，保留拍照+相册两个选项），选择后压缩(限宽约800px)生成缩略图预览 | 无（不参与计算） |
| | 款号/备注 | 文本，用于历史记录识别 | 无 |
| 材料 | 重量(克) | | ✅ 材料开关 |
| | 纱线单价(元/公斤) | | 同上 |
| 织机 | 织机时长(分钟) | | ✅ 织机开关 |
| | 织机单价(元/分钟) | | 同上 |
| 加工 | 缝盘(元) | | ✅ 缝盘开关 |
| | 辅料(元) | | ✅ 辅料开关 |
| | 后整(元) | | ✅ 后整开关 |
| 工艺 | 动态列表：名称+金额，可"＋添加"多行，逐行可删除 | 求和得到工艺合计 | ✅ 工艺总开关（一键关闭全部工艺项，无需逐条删除） |
| 利润 | 固定金额(元) | 直接加到小计上，不是百分比 | ✅ 利润开关，默认**关** |
| 税 | 税率，默认13%，可改 | | ✅ 税开关，默认**开** |

## 计算公式

```
小计 = (材料开? 重量(克)÷1000 × 纱线单价 : 0)
     + (织机开? 织机时长 × 织机单价 : 0)
     + (缝盘开? 缝盘 : 0)
     + (辅料开? 辅料 : 0)
     + (后整开? 后整 : 0)
     + (工艺开? 工艺列表金额求和 : 0)

总价 = (小计 + (利润开? 利润 : 0)) × (税开? 1+税率 : 1)
```

顺序固定为：先加利润，再乘税率（利润也要交税）。

之前设想的"含料价/不含料价"两套结果，现在统一为**只显示一个总价**，随开关状态实时变化——把"材料"开关关掉即得到不含料价，不再维护两套并行逻辑。

页面底部悬浮栏始终显示当前总价（大字），旁边是"保存记录"按钮。任何字段或开关变化，总价立即刷新，无需点击"计算"。

## 历史记录

- 点击悬浮栏"保存记录"，把当前所有字段值、开关状态、压缩后的图片、计算结果存为一条记录，写入浏览器 `localStorage`。
- 不点击不会自动保存，避免历史里全是试算的中间状态。
- "历史"标签页：记录按时间倒序列出，每条显示缩略图、款号、日期、总价。
- 支持删除单条记录（用于清理已导出的旧记录，控制 localStorage 空间——图片占地方，本地存储上限一般几 MB，预计可存约几十到一百条）。
- 换手机、清浏览器数据会丢失历史，导出的 Excel 是唯一的备份方式。

## 导出

- "历史"页面提供"导出 Excel"按钮，使用浏览器端的 SheetJS (xlsx.js) 库，直接在本地生成真正的 `.xlsx` 文件，无需联网、无需后端。
- 导出当前历史列表里的**全部**记录，每条一行，列包括：日期、款号、重量、纱线单价、织机时长、织机单价、缝盘、辅料、后整、工艺明细(合并成一行文字，如"纽扣15/绣花30")、各开关状态(开/关文字)、利润、税率、**总价**。
- 不含图片列（图片体积大，不适合塞进表格单元格）。
- 导出后记录不会自动清空，需手动删除已导出的旧记录来腾出空间。

## 技术实现

- 单个 HTML 文件，内嵌 CSS/JS，双击可在手机浏览器直接打开，也可添加到主屏幕当图标用。
- 为支持导出真正的 .xlsx，需要把 SheetJS 库内嵌进同一文件（体积会增加到约 1MB 左右），保证完全离线可用。
- 所有输入使用 `inputmode="decimal"` 触发数字键盘，适配手机快速录入。
- 数据存储：浏览器 `localStorage`，无后端、无数据库。

## v1.1 补充（2026-07-06）

上线后追加的两个功能：

- **清空/新建按钮**：报价页右上角，点击把所有字段/开关/图片/工艺列表重置为默认状态，不会自动保存当前内容——方便连续报多个不同款的价，需要保留的必须先点"保存记录"。
- **客户名称**：新增一个字段，放在图片和款号之间，用 `<input list>` + `<datalist>` 实现——既能像下拉框一样选历史客户，也能直接输入新名字。列表从空开始，每次保存记录时把当时填的客户名（去重、trim）追加进一个单独的 `localStorage` 列表（key: `garmentQuoteCustomers`），下次自动出现在候选里，不需要预先维护名单。客户名称会存进每条历史记录，历史列表里显示为"客户名 · 日期"，导出 Excel 时在"日期"后新增一列"客户名称"。
